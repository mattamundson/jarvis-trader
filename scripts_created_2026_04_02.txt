6. [ ] Install PM2 globally: npm install -g pm2
7. [ ] Verify ecosystem.config.js is updated
8. [ ] Test scripts manually: .venv\Scripts\python scripts/daily_health_check.py
9. [ ] Start PM2: pm2 start ecosystem.config.js
10. [ ] Verify processes running: pm2 status
11. [ ] Save PM2 state: pm2 save && pm2 startup
12. [ ] Monitor logs: pm2 logs jarvis-morning-brief
