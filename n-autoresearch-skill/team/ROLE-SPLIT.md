# Suggested role split

## Research operator

Focus:
- selecting experiments
- editing `train.py`
- writing hypotheses
- interpreting results

## Execution steward

Focus:
- environment validation
- GPU pool awareness
- log parsing
- finalize/keep/reset hygiene
- handoff quality

## Reviewer

Focus:
- code complexity vs gain
- whether a kept commit should remain the new baseline
- whether near-misses should be combined later

A single person can play all three roles, but explicitly naming them reduces sloppy session endings.
