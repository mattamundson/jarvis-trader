# Kickoff prompts

## Minimal start

```text
Use the n-autoresearch skill. Read program.md, propose a run tag, verify the environment, and kick off a baseline experiment.
```

## Operator mode

```text
Operate this repo using the n-autoresearch skill. Keep edits limited to train.py, register every experiment, and report keep vs reset after each run.
```

## Conservative mode

```text
Use the n-autoresearch skill, but be conservative: prefer small diffs, avoid high-crash experiments, and explain each hypothesis before running it.
```

## Summary mode

```text
Use the n-autoresearch skill to summarize the best experiments for the active tag, list near-misses, and recommend the next 3 experiments.
```
