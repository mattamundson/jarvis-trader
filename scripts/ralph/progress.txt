## Codebase Patterns
- gstack bin/ scripts expect to be called via full path: ~/.claude/skills/gstack/bin/gstack-config
- SKILL.md files are generated from .tmpl templates — never edit SKILL.md directly, edit .tmpl
- bun build --compile takes ~85s per binary in this environment — plan for timeout accordingly
- browse binary is platform-specific: compile on each target platform (Linux/macOS/Windows WSL2)
- gstack config lives at ~/.gstack/config.yaml — created by ./setup or manually
- Skill symlinks: ~/.claude/skills/<skill-name> -> .claude/skills/gstack/<skill-name>
- skill_prefix=false means skills are invoked as /review not /gstack-review
