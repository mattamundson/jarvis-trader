PART B: SOUND ALERTS SYSTEM
================================================================================

STEP 6: SoundAlertManager Library
──────────────────────────────────

✓ lib/sound-alerts.ts (NEW - 169 lines)

  Pure Web Audio API implementation (NO external files)

  Features:
  - Lazy-initialized AudioContext (first sound only)
  - Async/Promise-based sound playback
  - Automatic fade-in/out (no clicks/pops)
  - Context suspension/resumption handling
  - Global mute toggle and volume control

  Sound Types:
  ┌─────────────────────────┬──────────────────────────┐
  │ Method                  │ Sound Pattern            │
  ├─────────────────────────┼──────────────────────────┤
  │ tradeSignal()           │ 440Hz → 660Hz ascending  │
  │                         │ 100ms each, positive     │
  ├─────────────────────────┼──────────────────────────┤
  │ killSwitchAlert()       │ 880Hz → 440Hz → 220Hz    │
  │                         │ 100ms each, urgent       │
  ├─────────────────────────┼──────────────────────────┤
  │ circuitBreakerWarning() │ 660Hz single, 200ms      │
  │                         │ Medium priority          │
  ├─────────────────────────┼──────────────────────────┤
  │ orderFill()             │ 880Hz single, 100ms      │
  │                         │ Quick confirmation       │
  ├─────────────────────────┼──────────────────────────┤
  │ error()                 │ 220Hz single, 300ms      │
  │                         │ Low frequency warning    │
  └─────────────────────────┴──────────────────────────┘

  API Methods:
  - toggleMute() / setMuted(bool) / getMuted()
  - setVolume(0.0-1.0) / getVolume()
