HB-1 No broker-side STP orders in the codebase  (HIGHEST SEVERITY)

grep -rn "STP" engine/execution/ engine/agents/ engine/trader/ engine/pipeline/ returns zero matches. Trader computes stop_price, writes to paper_trades.stop_loss for display, nothing submits to IBKR.

  • engine/backtest/trend_signals.py:10-12 docstring: "trailing stop" is static at entry bar — full trailing was never built.
  • engine/execution/ib_gateway.py:510-518 supports order_type="STP" but no caller invokes that path.
  • Consequence: engine crash or network disconnect mid-trade = naked position until manual flatten. With pm2 restart count 558 (see OU-1), not hypothetical.
  • Fix: after entry fill confirmed, submit child STP via place_paper_order(order_type="STP", aux_price=stop_price, parent_order_id=<entry_id>). Broker-side, not Python-side.

Tracked as Q2-P2.7. Resolves via decision Q2-D6 (parent/child OCA vs bracket).

HB-2 Position-size gate rejects every MES order

At engine/risk/safety_layer.py:608-613:

estimated_value = quantity * estimated_price
if estimated_value / portfolio_equity > MAX_POSITION_SIZE_PCT:
    return False, "Position exceeds max size..."
  • MAX_POSITION_SIZE_PCT = 0.10
  • 1 MES @ ~$7,130 × $5 = ~$35,650 notional
  • Against INITIAL_CAPITAL=10000 → 356% of equity → reject
  • No futures branch in _check_order_value_limits().

Fix options:

  • (a) Call sync_from_broker() on startup so portfolio_equity reflects real IBKR paper equity (~$1M typical).
  • (b) Add if symbol in FUTURES_SYMBOLS: use margin_requirement(symbol) branch.
  • Recommendation: (a) first (smaller change), then (b) as defense-in-depth.

Tracked as Q2-P2.8. Resolves via decision Q2-D7.

0. Vision

Transform JARVIS TRADER from a single-strategy, single-instrument, paper-only system into a multi-strategy, multi-instrument, semi-autonomous trading platform with:

  • Real-time data fabric (no more stale CSVs)
  • Strategy ensemble (trend + mean-reversion + breakout per instrument, router decides)
  • Agent-native intelligence (LLM reasoning chains do the heavy lifting; humans approve, don't decide)
  • Continuous learning loop (n-autoresearch + A/B paper-canary + Gate v2 governance)
  • Multi-surface approval (WhatsApp, voice, dashboard — whichever you're near)

Success metric (end of 2026): 3+ validated strategies live across 2+ instruments, ≥90 days forward-test profitable, ≥$X live capital deployed (Tier 3 decision), agent-driven signals with <60s human approval latency.
