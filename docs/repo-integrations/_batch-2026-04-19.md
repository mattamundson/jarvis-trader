## Process notes for next batch

Two improvements from this sweep's missteps:

1. **Dispatch general-purpose agents, not Explore**, when the agent needs
   to write files. Explore agents are read-only and will silently produce
   analysis text without landing it on disk. I had to write 6 of the 10
   analysis files post-hoc from their returned summaries.
2. **Always verify the Write tool is reachable** before fanning out. A
   pre-flight `test_write_capability.md` in a throwaway path would have
   caught the read-only constraint within 10 seconds instead of 10
   minutes of wasted agent time.
