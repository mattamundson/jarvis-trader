## What the pilot validates

- The skill workflow (fetch → cross-reference 9 surfaces → classify → write doc) produces consistent, actionable output across repo types (trading, UI, agent tooling, general skill).
- Off-axis value is real: 4 of 5 noise-bucket repos had legitimate integration proposals on non-trading surfaces.
- Parallel haiku agents handled the task fine — no upgrade to sonnet needed for this depth.
- Cache-first fetch pattern works; fallback to `gh api` is seamless.

## What the pilot does NOT validate

- **True noise-detection rate.** I picked 5 repos suspected to have value. A blind sample from the full 97 would reveal how often the skill correctly returns `no-fit` across all surfaces.
- **Full 97-sweep duration.** 5 agents × ~90s each ran in parallel. 97 agents can't run in parallel at once; batches of 10 would take ~20 minutes of wall-clock plus review time per batch.
- **Integration implementation quality.** The skill produces proposals, not merged code. Each partial-integrate still needs implementation + tests.
