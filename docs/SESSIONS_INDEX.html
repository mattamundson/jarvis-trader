Conventions

Filename pattern: SESSION_<YYYY-MM-DD>_<short_topic>.html

Lifecycle: session HTMLs are frozen historical snapshots — once a session ends, the file is never edited. New sessions create new files; this index gets a new entry at the top.

What belongs in a session HTML:

  • What shipped (commits, files, surfaces) on that specific date
  • Activation-state changes (which env flags flipped on/off)
  • Decisions made + their rationale (since they decay fastest from git log)
  • Risks discovered + mitigation status
  • Operator cheatsheet for what changed
  • Recommended next steps coming out of the session

What belongs in the complete overview instead:

  • Every engine endpoint, analyst, strategy, table, broker, dashboard page
  • Full Hermes ecosystem inventory
  • Every runbook + every scheduled task
  • Current evergreen reference state — updated as the system evolves
