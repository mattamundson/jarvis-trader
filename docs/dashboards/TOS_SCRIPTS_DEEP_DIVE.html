Core Formula — 3-Bar Single Print Patterns

Core Formula
buy_volume = volume × (close - low) / (high - low) sell_volume = volume × (high - close) / (high - low) buy_percent = buy_volume / (buy_volume + sell_volume) × 100 sell_percent = sell_volume / (buy_volume + sell_volume) × 100 buyers_winning = buy_volume > sell_volume If buyers winning: BiggerVolume = buy_volume (GREEN histogram on top) SmallerVolume = sell_volume (RED histogram, smaller) Else: BiggerVolume = sell_volume (RED histogram on top) SmallerVolume = buy_volume (GREEN histogram, smaller) Note: Edge case when high == low (doji) → both volumes = 0, no signal
Trading Significance
Volume Stack must AGREE with KAMA direction to get a STRONG_BULL or STRONG_BEAR Layer 3 rating. Divergence (price above KAMA but sellers dominant, or red bars with green histogram) = LEAN_BULL not STRONG_BULL → smaller position size assigned by Layer 5. Watch for volume dominance to SHIFT before price confirms a reversal.

Keep Tscorev2 regardless — it's the only one with the score oscillator output. They all rely on the same underlying formula though; any parameter tuning must be applied to all three.

PARTIAL Finding 4 — All 4 Keltner Scripts Share Identical SMA(TrueRange, 20) Formula

OB_Omega_5m, OB_Omega_15m, OB_Omega_30m, and kelt_3.01 all compute Keltner bands identically: SMA(close, 20) ± factor × SMA(TrueRange, 20). The three OMEGA scripts could theoretically be a single script with a period input (they already have period as a user input).

Action: These serve different default timeframes for quick chart setup — functionally acceptable for workflow. However, maintaining 3 nearly-identical scripts is overhead. Consider consolidating to: kelt_3.01 (extreme fade, 3.0×) + one OMEGA script (user changes period input). The MACD "Closed Door" feature in the OMEGA scripts is valuable and should be preserved.

INTENTIONAL Finding 5 — Two Gap Detection Methods Are NOT Redundant

AA_CoreyGapfinderv1STUDY.ts (Corey) draws horizontal S/R zone lines with rightward extensions that persist until filled. GAPS_Chetan1STUDY.ts simply colors bars cyan/orange on gap opens. Different visual output serving completely different purposes — one is a structural S/R tool, the other is a quick visual scan aid.

Action: Keep both. They are complementary. Use Corey GapFinder for the S/R levels and zone targets. Use Chetan Gap Bars for the at-a-glance open type identification. Note the 0.10-point threshold in Chetan may need adjustment for high-priced instruments like NQ.
