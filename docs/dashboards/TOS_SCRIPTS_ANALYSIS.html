01Executive Summary

The JARVIS TRADER system integrates 34 ThinkScript (.ts) files located in thinkorswim-scripts/ as the visual charting backbone of a fully automated AI trading pipeline. Of these 34 files, 21 are unique studies actively used — the remaining 13 are TOS-generated nested shared_ duplicates automatically created when ThinkOrSwim exports complex studies with sub-study dependencies.

The integration is bidirectional: TOS scripts are reimplemented as Python functions in engine/backtest/indicators.py, enabling JARVIS to reproduce every indicator calculation internally for backtesting and live signal generation. In the reverse direction, the ThinkScriptGeneratorAgent can generate new ThinkScript code from JARVIS analysis results, which can then be pasted back into ThinkorSwim.

Signal flow does not go directly from TOS to JARVIS. Instead, TOS charts are used for visual confirmation and alert setup. The actual webhook signal path runs through TradingView via a Pine Script strategy bridge. Alerts fire HTTP POST webhooks to POST /webhook/tradingview, which then feeds the 5-stage AI pipeline for decision-making and IBKR order execution.

The 34 scripts implement a "Tony Stark" 5-Layer Framework: Layer 1 (Regime), Layer 2 (Structure), Layer 3 (Bias), Layer 4 (Entry Timing), and Layer 5 (Position Sizing). Each layer answers a precise trading question and feeds a specific set of Python signal functions in engine/backtest/signals.py.

Example: STC Python Implementation

# engine/backtest/indicators.py
def stc(close: pd.Series, fast: int = 23, slow: int = 50,
        k: int = 10, d: int = 3) -> pd.Series:
    """Schaff Trend Cycle — matches ThinkScript STC implementation."""
    ema_fast = close.ewm(span=fast, adjust=False).mean()
    ema_slow = close.ewm(span=slow, adjust=False).mean()
    macd = ema_fast - ema_slow
    # First Stochastic on MACD
    lowest_macd = macd.rolling(k).min()
    highest_macd = macd.rolling(k).max()
    stoch1 = (macd - lowest_macd) / (highest_macd - lowest_macd + 1e-10) * 100
    d1 = stoch1.ewm(span=d, adjust=False).mean()
    # Second Stochastic on D1
    lowest_d1 = d1.rolling(k).min()
    highest_d1 = d1.rolling(k).max()
    stoch2 = (d1 - lowest_d1) / (highest_d1 - lowest_d1 + 1e-10) * 100
    return stoch2.ewm(span=d, adjust=False).mean()  # Final STC value 0–100

11Broker Architecture

⚠
Critical: TOS Cannot Execute Futures Orders

ThinkOrSwim / Charles Schwab cannot directly execute futures orders via API. All futures trading (MES, MNQ, MCL, MGC) routes through Interactive Brokers (IB Gateway). TOS is used only for visual charting and alert setup.

Equity Options SPY, QQQ, AAPL, TSLA Charles Schwab Schwab API — engine/execution/schwab_connector.py 60% COMPLETE

# engine/execution/order_router.py
def route_order(symbol: str, order: Order) -> Broker:

        return IBGatewayConnector(port=4002)  # Paper port
