Consequences encoded in the pipeline (honest, documented in the module docstring):

- **Prices are daily bars, not bid/ask snapshots.** The cache models
  `bid/ask = mid × (1 ± relative_half_spread)` (default 2%) so the scaffold's
  `FlatSlippage` keeps working with an explicit cost knob.
- **IV is solved** by Black-Scholes inversion from the daily close
  (`implied_volatility()` bisection over `options.premium_calculator.black_scholes_price`),
  then Greeks via the engine's `options.greeks_monitor.calculate_greeks`.
  American-exercise approximation documented as research-grade.
- **Strike selection is ladder-discretized** (default $5 rungs around the theoretical
  30-delta strike) to bound API calls; selection noise is part of the strategy.

## 5. Methodology

### A-priori config (locked before any data was seen — no post-hoc tuning)

- Signals: RSI(14) mean reversion on daily closes — `RSI ≤ 35 → LONG`,
  `RSI ≥ 65 → SHORT`, 10-trading-day cooldown.
- Spread: vertical **debit** spread, long leg nearest 0.30 |delta|, width 1 rung.
- Expiry: nearest monthly (3rd Friday) with DTE ≥ 30.
- Costs: mid = close/VWAP; modeled bid/ask ±2%; `FlatSlippage` +5 bps; ×100 multiplier.
- `n_combos = 1` — DSR sees **no** grid-search selection bias; this is the honest
  single-config claim.
- Strike ladder: $5 rungs centered on the theoretical 30-delta strike
  (from 20-day realized vol), ±2/+3 rungs.

### Gate v2

`scripts/gate_v2_orchestrator.py --results-file <SPY/QQQ options results> --symbol SPY
--family options --rank 1` → writes `data/gate_v2_verdicts/SPY_options_rank1.json`.
Core gate: MBB PF CI lower ≥ 1.10, p_positive_edge ≥ 0.95, MC-95th DD ≤ 6%,
DSR ≥ 0.10 (4/4). Alt gate: 5/5 with aux evidence (not produced here — UNSCORED).

## 8. Honest limitations

1. **Bid/ask modeled, not observed** (tier 403 on snapshots). Spread assumption ±2%
   is conservative for liquid SPY/QQQ monthlies but not measured.
2. **IV solved from daily closes** — no term structure, no IV rank; IVR fixed at 50.
3. **Hold-to-expiry only** — the scaffold's deferred exit rules remain deferred.
4. **n_combos=1** — a single a-priori config, so the core gate is the only path;
   no alt-evidence reports (rolling WFO / fixed params / cost sweep) were produced.
5. **~5 calls/min tier** — full-chain cache builds are slow; focused bands keep a
   single-symbol run to ~30 min. A Polygon tier upgrade (snapshot product) would
   both speed this up and supply real bid/ask/Greeks.
