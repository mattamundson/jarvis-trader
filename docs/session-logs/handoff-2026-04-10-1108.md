## 6. KEY DECISIONS MADE

### Pine Script compatibility rules (canonical — apply to all JARVIS_*.pine)

| Rule | Why |
|---|---|
| Use 8-digit hex literals (`#RRGGBBAA`) for all color constants at global scope | `color.*` namespace is unresolvable by MCP parser |
| Single-line ternary expressions only | Multi-line continuations are rejected |
| Functions defined at global scope, called from `if` blocks | Function defs inside `if` are rejected |
| No `color` type annotation on declarations (`color c = ...`) | Shadowing collision with namespace |
| Keep `//@version=5` for now | v5 warning is severity 4 (not error), upgrade later |

  weighted-average entry price. Prevents 5 repeated MCL LONGs from looking
