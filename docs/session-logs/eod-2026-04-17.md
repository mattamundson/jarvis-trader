## ERRORS & WARNINGS

### ⚠️ WARNING — Intermittent Health Endpoint Crash (main.py:582)

The engine error log contains repeated `TypeError: 'bool' object is not callable`
at `engine/main.py` line 582:

```
"ibkr_connected": bool(getattr(data_manager.ibkr, "is_connected", False))
                  ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
TypeError: 'bool' object is not callable
```

**Diagnosis:** `data_manager.ibkr.is_connected` appears to be returning a value that,
when passed as the first argument to `bool()`, triggers this error. This likely means
`data_manager.ibkr` is itself a `bool` (e.g., `False`) rather than an IB connection object,
causing `getattr(False, "is_connected", False)` to return `False`, and the `bool`
builtin may have been shadowed in that scope. The `/health` endpoint currently returns
200 intermittently but crashes on some invocations.

**Impact:** Health checks may silently fail on some calls. Dashboard watchdog reliability
may be affected. Not a trading-safety issue — kill switch and risk layer are unaffected.

**Recommended fix:** Investigate `data_manager.ibkr` initialization. If IBKR disconnects
and `ibkr` is reassigned to `False`, the health check needs a null-guard:
```python
ibkr_obj = getattr(data_manager, 'ibkr', None)
"ibkr_connected": ibkr_obj is not None and getattr(ibkr_obj, 'is_connected', False) not in (False, None)
```
